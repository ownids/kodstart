# КодСтарт — ИС записи на курсы программирования

Минимально жизнеспособная информационная система онлайн-школы программирования.
Поток: **регистрация → авторизация → работа с заявками**; администратор управляет статусами заявок.

Выполнено в рамках производственной практики по ПМ.01 «Проектирование и разработка информационных систем».
Автор: Мамажонов Азамат Валижон Угли, группа ОКИП-12209МОвр.

## Технологии
Python 3 + Flask, MySQL 8 / MariaDB (PyMySQL), HTML5, CSS3 (Flexbox, Grid, медиазапросы), JavaScript (без фреймворков), Git.

## Сущности БД
| Таблица | Назначение | Ключевые поля |
|---|---|---|
| `users` | пользователи (клиенты и администратор) | PK `id`, уникальные `login`, `email`; `role` = user/admin |
| `courses` | каталог курсов | PK `id`; `title`, `duration_weeks`, `price` |
| `statuses` | справочник статусов заявки | PK `id`; `name` (4 статуса) |
| `applications` | заявки на обучение | PK `id`; FK `user_id`, `course_id`, `status_id`; `start_date`, `payment_method` |
| `status_history` | история смены статусов (модуль 3) | PK `id`; FK `application_id`, `status_id`, `changed_by` |

Связи: пользователь 1:N заявки, курс 1:N заявки, статус 1:N заявки, заявка 1:N записи истории.
ER-диаграмма — `docs/er-diagram.pdf`.

Статусы заявки: **Новая → Идёт обучение → Обучение завершено**, а также **Отменена**.

## Сценарии
1. **Регистрация** (`/register`): все поля обязательны; логин — латиница/цифры/«_», 4–30 символов, уникальный (проверка на лету через `/api/check-login` и на сервере); пароль — от 6 символов (хранится в виде хэша); ФИО — кириллица; телефон — `8(XXX)XXX-XX-XX` (маска ввода); email — уникальный.
2. **Авторизация** (`/login`): сообщение «Неверный логин или пароль», ссылки «вход ↔ регистрация»; администратор перенаправляется в панель, клиент — в кабинет.
3. **Кабинет пользователя** (`/cabinet`): список своих заявок со статусами и форма новой заявки (курс, желаемая дата начала — не в прошлом, способ оплаты, комментарий).
4. **Панель администратора** (`/admin`): все заявки, поиск по ФИО/курсу, фильтр по статусу, пагинация, смена статуса без перезагрузки с всплывающим уведомлением; каждая смена пишется в `status_history`.

## Запуск
```bash
pip install -r requirements.txt
mysql -u root -p < database/schema.sql
mysql -u root -p < database/seed.sql
mysql -u root -p < database/migrations/002_module3.sql
# параметры подключения (по умолчанию localhost / root / пустой пароль / kodstart)
export DB_USER=root DB_PASSWORD=ваш_пароль
python app.py        # http://127.0.0.1:5000
```
Учётная запись администратора: **admin / KodStart2026**.

## Структура
```

```
