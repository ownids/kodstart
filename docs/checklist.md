## Производительность
- [x] Один CSS-файл и один JS-файл, JS подключён с `defer`
- [x] Ленивая загрузка изображений слайдера (lazy loading)
- [x] Индексы БД под фильтры админ-панели (`idx_app_status`, `idx_app_created`)
- [x] Пагинация списка заявок (по 5 на странице) вместо выдачи всех записей
- [x] Мета-описание страницы и семантическая разметка (header, nav, main, footer) для SEO

## Микроанимации
- [x] Hover кнопок: подъём на 1 px и тень; active — лёгкое сжатие
- [x] Hover карточек курсов: подъём на 4 px и тень
- [x] Слайдер: плавная смена (opacity + scale, 0,6 с) и полоса прогресса автопрокрутки
- [x] Toast-уведомления: выезд снизу и плавное исчезновение
- [x] Появление элементов списка заявок (fadeUp с задержкой)
- [x] «Встряхивание» поля с ошибкой
- [x] Учёт `prefers-reduced-motion` — анимации отключаются по настройке ОС

## Доступность и адаптивность
- [x] Видимая обводка фокуса (`:focus-visible`), ссылка «Перейти к содержимому»

- [x] Проверено на 390×844 (смартфон) и 1440×900 (десктоп): таблица заявок на мобильном превращается в карточки, весь функционал сохраняется
