# UI-гайд ИС «КодСтарт»

## Цвета
| Роль | Цвет | Где используется |
|---|---|---|
| Основной (primary) | `#0F766E` | кнопки, ссылки, активные элементы, логотип |
| Основной тёмный | `#115E59` | hover кнопок |
| Акцент | `#F59E0B` | прогресс слайдера, фокус-обводка |
| Текст | `#0F172A` | заголовки и основной текст |
| Вторичный текст | `#64748B` | подписи, подсказки |
| Фон | `#F8FAFC` | фон страницы |
| Поверхность | `#FFFFFF` | карточки, панели, шапка, футер |
| Ошибка / успех | `#DC2626` / `#16A34A` | валидация форм, уведомления |

Контраст основного текста к фону — более 15:1, белого текста на кнопке `#0F766E` — 5,4:1 (соответствует WCAG AA).

## Типографика
Шрифт: Inter (запасные — Segoe UI, Arial, sans-serif).
Заголовок H1 — 1,6 rem на смартфоне / 2 rem на десктопе, H2 — 1,3 rem, основной текст — 1 rem (16 px), подписи — 0,8–0,9 rem.
Межстрочный интервал — 1,5.

## Сетка и отступы
Базовый шаг — 8 px (`--space`), все отступы кратны ему.
Контейнер — до 1120 px, поля 16 px.
Подход mobile-first: базовая вёрстка для 390×844 px, медиазапросы `min-width: 768px` и `1024px`.
Карточки курсов: 1 колонка (смартфон) → 2 (планшет) → 4 (десктоп) на CSS Grid.
Скругления — 12 px, тень — `0 4px 16px rgba(15,23,42,.08)`.

## Компоненты
Кнопки — высота не менее 44 px (удобно нажимать пальцем), состояния hover / active / focus-visible.
Поля ввода — рамка 1,5 px, при фокусе бирюзовая обводка, при ошибке красная рамка и текст ошибки под полем.
Статусы заявок — цветные «таблетки»: Новая (синий), Идёт обучение (янтарный), Обучение завершено (зелёный), Отменена (серый).
Уведомления (toast) — появляются снизу, исчезают через 3,5 с.
